Easy Gym PWA v316X — пакет для GitHub Pages / SEPT

1. Распакуйте архив.
2. Загрузите ВСЁ содержимое прямо в SEPT: index.html должен быть в SEPT/index.html.
   Папки icons, lang, info и Branding сохраняйте вместе с их содержимым.
3. Дождитесь публикации GitHub Pages; откройте опубликованную страницу в Safari.
4. Добавьте её на экран «Домой». Если ранее добавленный ярлык показывает старую
   иконку, проверьте новую страницу в Safari и создайте новый ярлык.

Логотип обновлён в шапке, печатных отчётах, иконках, favicon и manifest.
Адаптация размеров сохранена из v315X.
Ключи данных совпадают с PWA v315X в той же папке, поэтому планы SEPT сохраняются.
Отдельная новая папка использует отдельные тестовые данные.
SHARE PLAN открывает окно Easy Gym с точным текстом:
SHARE available in App-Store Version

All icon sizes are deterministic resizes of that approved artwork, not new generations.
Native and web PNGs are opaque RGB. Maskable PNGs retain the approved central mark;
the decorative outside frame/background may be cropped by the launcher mask.

Validated: icon sizes/pixels, embedded logos, JavaScript syntax, local asset links,
manifest/service-worker resources, archive integrity and checksums.
Not validated: Xcode compilation, physical iPhone/iPad, visual browser rendering.
