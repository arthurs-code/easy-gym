EASY GYM PWA v315X — ТЕСТОВАЯ ВЕРСИЯ ДЛЯ GITHUB PAGES

1. Распакуйте ZIP.
2. Откройте НОВУЮ папку в репозитории easy-gym на GitHub.
3. Загрузите в неё ВСЁ содержимое архива. index.html, styles.css,
   responsive.css, responsive.js, manifest.json и service-worker.js
   должны лежать прямо в этой папке. Сохраните вложенные icons, lang, info.
   Не загружайте ZIP и не создавайте ещё один вложенный уровень папок.
4. Дождитесь завершения публикации GitHub Pages.
5. На iPhone/iPad откройте в Safari опубликованный адрес новой папки
   (адрес GitHub Pages, а не github.com/.../tree/...).
6. Через меню «Поделиться» добавьте страницу на экран «Домой».

Для обычного GitHub Pages этого репозитория адрес имеет вид:
https://arthurs-code.github.io/easy-gym/ИМЯ-НОВОЙ-ПАПКИ/
Это шаблон адреса: фактическая публикация и имя новой папки ещё не проверены.
Если настроен собственный домен, используйте адрес опубликованного сайта.

Проверка на устройстве:
- PLAN, GO, LOG, MGMT, SUPPORT, INFO; все пять языков.
- Вертикальное и горизонтальное положение; узкое окно iPad.
- Создание упражнения, клавиатура, прокрутка списка, закрытие окна.
- Длинные названия, большие значения TOTAL, доступность кнопок.
- SHARE PLAN показывает окно Easy Gym с точным текстом:
  SHARE available in App-Store Version

Тестовая версия использует отдельные ключи данных для новой папки.
Она не импортирует автоматически планы и журнал из euro5.
Её service worker очищает только собственный кэш данной тестовой папки.
Старая версия остаётся без изменений; для тестов используйте новую папку.
