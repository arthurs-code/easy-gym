# PWA_BG — Easy Gym PWA v317X

Отдельная копия Easy-Gym-PWA-v317X-GitHub. Номер версии НЕ изменён.
Исходный пакет v317X сохранён без изменений. Языки этой копии: English (EN)
и Български (BG). Язык по умолчанию — English; BG выбирается в меню языков.

## Публикация

Распакуй PWA_BG.zip. Загрузи ВСЁ содержимое папки Publish в отдельную
папку PWA_BG на GitHub Pages: PWA_BG/index.html, PWA_BG/js и т. д.
Не добавляй дополнительную папку Publish в опубликованный путь.
Открой опубликованную PWA в Safari на iPhone и выбери «Поделиться» →
«На экран Домой». Название приложения и иконка остаются Easy Gym.
Ничего автоматически не опубликовано.

Новый путь использует отдельные данные тренировок. Для переноса используй
BACKUP в исходной PWA и RESTORE в новой копии. Исходную папку не заменяй.

## Редактирование

- Content/en/ui.json — английские кнопки, сообщения и календарь.
- Content/bg/ui.json — болгарские кнопки, сообщения и календарь.
- Content/<язык>/info.html — раздел INFO с сохранённой разметкой и иконками.
- Content/bg/exercises.json — переводы всех 18 стандартных упражнений.
- Content/exercise-library.json — постоянные английские идентификаторы упражнений.
- Content/languages.json — включены только en и bg, язык по умолчанию en.
- Source/ — исходная разметка, логика, стили и иконки v317X.

После редактирования запусти BUILD-CONTENT.cmd (Windows) или
sh BUILD-CONTENT.sh (Mac/Linux). Требуется Node.js 18 или новее,
npm install не нужен. Для публикации уже собранной Publish Node.js не нужен.
Проверка: npm run check. Тесты: npm test.

В болгарском переведены интерфейс, календарь, сообщения, INFO и упражнения.
Точный текст специального PWA-окна SHARE сохранён по требованию проекта:
SHARE available in App-Store Version

Номер версии v317X, логика тренировок, элементы управления, стили, английский
контент и иконки сохранены. Кэш обновлён сборщиком по содержимому, без смены
номера версии. В публикуемом пакете нет языковых пакетов DE/FR/IT/ES.
Исторический Tests/v316X-baseline.json служит только прежней базой сравнения;
режим --baseline не предназначен для этой отдельной языковой копии.

Проверены сборка, оба языка, резервная INFO-копия, workflow редактора,
SHARE-попап и моделируемая работа offline/service worker. Визуальная проверка
на физических телефонах и планшетах не выполнялась.
