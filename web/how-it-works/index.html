How It Works

The Easy Gym workflow presented as one clear sequence.

Choose a date and create PLAN

Select the date, add exercises and define the workout values.

Activate PLAN and open GO

The selected plan becomes the active workout while the saved original remains protected.

Start training

Set completion becomes available after starting. TIME and TOTAL update during the workout.

Stop and save

The completed session is written to LOG with date, start time, duration and total work.

Open, compare and export

Open one LOG at a time, compare planned and completed values, then save Word or PDF.
