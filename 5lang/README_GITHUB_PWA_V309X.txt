Easy Gym PWA v309X

Based directly on approved PWA v308X.

Changes:
- PLAN: when no date is selected, the SAVE/SAVED row is fully hidden and cannot retain a visible SAVED state.
- GO: set progress (0/2, 1/2, etc.) cannot be changed before START TRAINING is activated.
- GO metric editing and adding exercises/rows before starting remain unchanged.
- After START TRAINING, set progress becomes available normally.

PLAN, GO, LOG, MGMT, SUPPORT, INFO, storage, exports, language switching and all unrelated functionality remain unchanged.
